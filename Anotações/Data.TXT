# Data Warehouse - repositório de dados unificado para armazenar grandes quantidades de informações de varias fontes

Os dados vem de várias fontes, passam pelo processo de -extrair, transformar, limpar, filtrar, carregar- e vão para o data warehouse para gerar relatorios, insights e visualização de forma agrupada

ETL = Extract Transform and Load

pode ter problemas com dados semi estruturados e nao estruturados, dificulta para machine learning

pode ser caro de manter e se tornam desatualizados, requer manutençao regular

mais complicado e caro para fazer atualizações, al;tamente otimizado , uso facilitado

# Data Lakes - repositorio de armazenamento centralizado altamente flexivel

Dados estruturados ou não, armazenados de forma bruta original, flexivel, duravel

consulta sem otimização, mas altamente acessível e rápido de atualizar, uso complexo mais difícil

permite aprendizado de máquina e análise preditiva, os dados podem ficar desorganizados dificultando utilização para análise de dados e business intelligence, falta de segurança e confiabilidade de dados

custo menor por gigabyte armazenado, melhor aproveitavel para uso futuro 

falta de estrutura de dados consistente e suporte transacional para ACID

ACID = Atomicidade Consistencia Isolamento Durabilidade
