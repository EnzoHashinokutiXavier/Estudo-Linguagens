Variaveis (tipos primitivos):

- Declarar variavel começando com letra minuscula ou numero ex : nomeSobrenome123
- nao usar caractere especial em variaveis, nao colocar espaço
- pode usar underline nas variaveis

- byte : -128 a 127 (1 byte de informação ou 8 bit)
- short : -32768 a 32767 (2 bytes de informação ou 16 bits)
- int : -2.147.483.648 a 2.147.483.647 (2 bilhoes, 4 bytes ou 32 bits)
- long : -9.223.372.036.854.775.808 a 9.223.372.036.854.775.807 (8 bytes ou 64 bits)
    valor do tipo long precisa colocar L no final ex : 123456789L

- float : 7 casas decimais depois do ponto (4 bytes ou 32 bits)
    coloca f no final ex : float real = 10.50f;
- double : 15 casas decimais apos o ponto (8 bytes ou 64 bits)

- String : texto "abc"
- char : caractere 'a'
- boolean : true ou false

Métodos :

<retorno> tipo de valor retornado

ex:
// modificador retorno nome argumentos

    for (int i = 0; i < cores.lenght; i++){

Classe abstrata : 

não permite variáveis contendo instancias dela 

ex: cada animal é agrupado como animal mas nao pode existir um ser que seja apenas animal (ex animal cachorro)

public abstract class Animal {
    public String nome;
    public int patas;
}


Métodos abstratos :

classe pai fornece apenas assinatura, delega o fornecimento da implementação a classe filha

ex : todo animal anda, mas cada um de um jeito diferente
public abstract void andar();


Interfaces :

no java uma classe filha so pode herdar uma classe pai
interface cria comportamento comum entre classes
são como classes abstratas mas so pode declarar metodos abstratos
um contrato que define uma série de métodos que uma classe deve implementar

ex:
public interface CSVGenerator {
    public String toCSV();
}

public class Pessoa implements CSVGenerator{
    ...
    @Override 
    public String toCSV(){
        ...
    }
}
